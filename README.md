# Markdown Editor

一款专注长文写作的桌面 Markdown 编辑器：**所见即所得的可视化编辑**、随时可切换的**源码模式**，以及由文档大纲实时生成的**思维导图**。所有文件都在本地读写，不依赖网络。

![可视化编辑界面](docs/screenshots/editor.png)

## 功能一览

- **可视化写作**：标题、列表、引用、表格、代码块、公式直接在页面上编辑，不必记忆语法
- **源码模式**：CodeMirror 6 驱动，语法高亮、行号折叠，适合精细调整 Markdown
- **思维导图**：一键把标题层级转成 Markmap 导图，支持缩放、平移与适应窗口
- **多标签页**：同时打开多个文档，未保存状态以圆点标记，关闭前会提示确认
- **目录浏览**：打开文件夹后以树形结构浏览其中的 Markdown 文件
- **文档导入**：Word、PDF、PPT、Excel、EPUB、RTF、CSV 等格式一键转成 Markdown
- **主题与排版**：亮色 / 深色主题、页面宽度、行高、字体、字号、打字机模式均可调整
- **文字样式**：选中文字即可改字体颜色、添加高亮底纹
- **本地优先**：文件保存在你选择的位置，设置仅存入本地

## 思维导图

点击工具栏上的「导图」，当前文档的标题层级就会渲染成思维导图，适合梳理章节结构与检查长文脉络。导图会跟随文档内容更新，右上角「适应窗口」可一键回到完整视图，也可以用鼠标滚轮缩放、拖拽平移。

## 双模式编辑

可视化模式用于日常写作，排版即时呈现；需要处理复杂语法或批量修改时，切换到源码模式逐行编辑。两种模式共享同一份内容，切换时不会丢失改动。

![Markdown 源码模式](docs/screenshots/source.png)

## 文档管理

- **新建 / 打开 / 导入**：新建空白文档、打开已有 Markdown 文件（可多选），或把 Office、PDF 文档转换成 Markdown
- **目录侧栏**：打开整个文件夹，按树形结构查找并切换文档
- **大纲导航**：展示当前文档的所有标题，点击即可跳转到对应章节
- **保存**：支持保存与另存为；未保存的文档在标签页与标题栏都有标记

## 个性化设置

工具栏右侧的齿轮按钮打开编辑器设置，包含：

- 默认编辑模式（可视化 / 源码）
- 界面字号与正文字号
- 正文字体（默认 / 衬线 / 等宽）、粗体颜色、编辑器背景色
- 页面宽度（紧凑 / 标准 / 宽屏 / 100%）、行高、打字机模式
- 源码编辑器字体与高度、图片最大宽度

设置会即时生效并自动保存，下次启动沿用。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 新建文档 | `Ctrl + N` |
| 打开文档 | `Ctrl + O` |
| 导入文档 | `Ctrl + Shift + O` |
| 保存 | `Ctrl + S` |
| 另存为 | `Ctrl + Shift + S` |
| 撤销 / 重做 | `Ctrl + Z` / `Ctrl + Y` 或 `Ctrl + Shift + Z` |

## 系统要求

- Windows 10 及以上（桌面应用）
- 无需额外安装运行环境，Markdown 文件保存在本地磁盘

---

技术栈：Tauri 2 + React 19 + Milkdown（可视化编辑）+ CodeMirror 6（源码编辑）+ Markmap（思维导图）。
